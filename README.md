# シノトレ

Synonym Quiz（Core #13〜16・Basic #13〜16、200語）を覚えるための単語アプリ。テストと同じく、シノニム（= の後ろ）を見て英単語を答えます。

- iPhone: Safariで開いて 共有 → ホーム画面に追加

## できること

- **クイック10問**：スキマ時間用。苦手・未学習の単語から優先して出題
- **答え方**：おまかせ（カード → 4択 → 入力と覚え具合で変わる）／4択／入力（本番形式）／カード
- **問題文**：シノニム／シノニム＋日本語／日本語。答えたあとは毎回、日本語の意味と発音が出ます
- **本番形式テスト**：1セット25問を番号順に入力。点数と日付が記録されます（問題用紙の Date / Score 欄と同じ）
- **苦手**：間違えた単語・★をつけた単語。入力で続けて正解すると卒業
- **単語**：一覧・検索、「英単語をかくす」で赤シート風に自己テスト
- **記録**：進み具合（%）、習得数、今日・合計の勉強時間、勉強した日数と連続日数、テスト日までの日別グラフ、1日の目標

日本語の意味は覚えやすいように短くまとめたものです（教材の辞書部分の転載ではありません）。記録はこの端末のブラウザ（localStorage `synotore:v1`）に保存されます。

## ファイル

- `data/words.js` 単語データ（答え・シノニム・品詞・日本語・頭文字ヒント）
- `tools/check.js` 解答ページの並びと一致しているかの検証（`node tools/check.js`）
